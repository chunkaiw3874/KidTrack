# KidTrack 小朋友目標追蹤（v1）

給家長使用的目標與獎勵追蹤工具。和 FitTrack 一樣是**單一檔案 PWA**（整個程式只有 `index.html`），放在 GitHub Pages 上就能用，也可以加到手機或平板主畫面。

---

## 1. 功能總覽

| 頁面 | 誰使用 | 功能 |
|---|---|---|
| ✅ 今日 | 家長 | 每個小朋友今天的目標；點圓圈打勾或取消，可補登最近 7 天；達成後按「已發放獎勵」 |
| 🎯 目標 | 家長 | 新增、編輯、封存、刪除目標；一個目標可以同時指派給多位小朋友 |
| 🧒 小朋友 | 家長 | 新增、編輯、刪除小朋友（暱稱＋動物頭像） |
| ⚙️ 設定 | 家長 | 設定 PIN、匯出或還原備份、清除資料 |
| 👀 展示頁 | 小朋友 | 大字體顯示進度、連續天數、獎勵；**只能看，不能修改** |

---

## 2. 三種目標類型

| 類型 | 規則 | 適合的例子 |
|---|---|---|
| **連續天數** | 執行日漏掉一天，連續天數**歸零重新計算** | 每天刷牙、連續 21 天早睡 |
| **累計天數** | 漏掉不歸零，累積到指定天數就達成 | 這個月練琴 10 天 |
| **一次性** | 完成一次就達成 | 讀完一本書、學會騎腳踏車 |

### 連續天數的計算細節

| 情況 | 結果 |
|---|---|
| 執行日沒打勾，而且那天已經過去 | 連續天數歸零 |
| **今天**還沒打勾 | 不算漏掉（今天還沒結束），連續天數維持昨天的數字 |
| 不是執行日（例如只選平日，遇到週末） | 跳過，不影響連續天數 |
| 曾經連續達到目標天數，之後中斷 | **仍算達成**，不會被取消 |
| 忘記打勾，隔天才補登 | 補登後自動重新計算，連續天數會恢復 |

### 目標狀態

| 狀態 | 意思 |
|---|---|
| 今天待完成 / 今天完成 / 今天休息 | 進行中 |
| 已達成 🎉 | 達到目標，等待家長發放獎勵 |
| 時間不夠了 | 在結束日期前，剩下的執行日已經不可能達成（可延長結束日期） |
| 已過期 | 過了結束日期仍未達成 |
| 尚未開始 | 開始日期還沒到（只在「目標」頁顯示） |

## 3. 部署到 GitHub Pages（約 5 分鐘）

1. 登入 GitHub，右上角 **＋ → New repository**
2. Repository name 填 `kidtrack`（可自訂），選 **Public**，按 **Create repository**
3. 在新的 repo 頁面點 **uploading an existing file**，把 `index.html` 和 `README.md` 拖進去，按 **Commit changes**
4. 進入 **Settings → Pages**
5. **Source** 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**
6. 等 1～2 分鐘，頁面上方會出現網址，格式是 `https://你的帳號.github.io/kidtrack/`

### 加到主畫面

| 裝置 | 步驟 |
|---|---|
| iPhone / iPad | 用 **Safari** 開網址 → 分享按鈕 → **加入主畫面** |
| Android | 用 Chrome 開網址 → 右上角選單 → **加到主畫面** 或 **安裝應用程式** |

### 之後要更新程式

在 repo 點 `index.html` → 右上角鉛筆圖示，或重新上傳覆蓋檔案 → Commit。**資料不會因為更新程式而消失**（資料存在裝置上，不在 GitHub）。

## 4. 資料存在哪裡

| 項目 | 說明 |
|---|---|
| 存放位置 | 這台裝置瀏覽器的 localStorage（瀏覽器內建的小型儲存空間） |
| 會上傳到 GitHub 嗎 | **不會**。GitHub 上只有程式碼，沒有任何小朋友資料 |
| 不同裝置會同步嗎 | **不會**。手機和平板各自獨立，可用「匯出 → 匯入」搬移 |
| 什麼情況會遺失 | 清除瀏覽器資料、換裝置、無痕模式、iPhone Safari 網頁版超過 7 天沒開（加到主畫面可避免） |

## 5. 資訊安全設計（已內建）

| 風險 | 程式中的防護 |
|---|---|
| **XSS 注入**（在名字欄輸入 `<script>` 之類的惡意程式碼） | 所有輸入的文字一律用 `textContent` 當純文字顯示，程式中完全不用 `innerHTML` |
| **資料被偷傳出去** | CSP 安全標頭設定 `connect-src 'none'`，網頁**無法連線到任何伺服器**；也不能載入外部程式 |
| **外部套件被竄改**（供應鏈攻擊） | 不使用任何外部套件或 CDN，全部程式都在一個檔案裡 |
| **惡意的備份檔** | 匯入時逐一檢查：只保留認識的欄位、限制文字長度、驗證日期格式、檔案上限 1MB |
| **PIN 外洩** | PIN 加鹽（salt）後以 SHA-256 雜湊儲存，不存原始數字；連錯 5 次鎖 30 秒 |
| **小朋友重新整理頁面跳出展示頁** | 最後停在展示頁時，重新開啟仍停在展示頁 |
| **搜尋引擎收錄** | 設定 `noindex`，告訴 Google 等搜尋引擎不要收錄 |
| **資料損毀** | 讀取失敗時先另存舊資料，不直接覆蓋 |
| **時區錯誤** | 日期一律用台灣本地時間計算（避免凌晨 0～8 點日期錯一天的常見 bug） |

### PIN 的限制（請了解）

PIN 是用來**防止小朋友誤觸或好奇**，不是銀行等級的密碼保護。懂技術的人拿到裝置，仍可從瀏覽器開發者工具看到資料。這對家庭使用已足夠，但請**不要用提款卡或手機解鎖密碼當 PIN**。

## 6. 建議的使用習慣

| 建議 | 原因 |
|---|---|
| 小朋友只用暱稱或小名 | 網址是公開的，雖然資料不在網上，暱稱仍是最保險的做法 |
| 每 1～2 週匯出一次備份 | 程式超過 14 天沒備份會在首頁提醒 |
| 備份檔存在 Google Drive 或電腦 | 手機壞掉時可以還原 |
| GitHub 帳號開啟雙重驗證（2FA） | 防止帳號被盜、網站被改成惡意內容。設定位置：GitHub → Settings → Password and authentication |
| 目標設小一點、短一點 | 例如先設 7 天連續，再挑戰 21 天；小朋友比較容易得到成就感 |
| 展示用的平板設定 PIN | 小朋友才不會跑進家長模式修改紀錄 |

## 7. 常見問題

| 問題 | 解答 |
|---|---|
| 忘記 PIN 怎麼辦？ | 在其他裝置還原最近的備份檔（備份不含 PIN）；或清除該網站的瀏覽器資料後重新匯入 |
| 想在爸爸和媽媽的手機都能打勾？ | 目前版本不支援同步。需要時可升級成雲端資料庫版本（例如 Supabase），會多出登入與權限設定 |
| 想補登 7 天以前的紀錄？ | 目前只能補登最近 7 天；更早的紀錄可以調整目標的開始日期 |
| 修改目標的開始日期或執行日會怎樣？ | 連續天數會依新設定重新計算，打卡紀錄不會刪除 |

## 8. 給維護者的技術說明

| 項目 | 內容 |
|---|---|
| 檔案 | `index.html`（HTML + CSS + JavaScript，無外部相依） |
| 儲存鍵 | `kidtrack.v1`（主資料）、`kidtrack.mode`（目前是家長模式或展示頁） |
| 核心邏輯 | `computeStats()` 計算連續天數、累計、達成、過期；`sanitizeState()` 驗證資料 |
| 測試範圍 | 連續歸零、今天未打勾不歸零、平日目標跳過週末、累計不歸零、時間不夠、過期、未開始、達成後中斷仍保持達成、跨月與閏年、惡意匯入資料過濾 |
| 修改提醒 | 新增顯示文字時請沿用 `h()` 函式（純文字），不要改用 `innerHTML` |
